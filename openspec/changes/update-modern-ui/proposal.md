# Change: Update Modern UI

## Why
The current single-tone dark layout feels flat and AI-generated, with basic blocks, limited depth, and minimal visual cues. We need a more expressive art-directed experience that feels premium and modern.

## What Changes
- Introduce a multi-layered gradient background system with subtle noise and glow accents to make the canvas feel intentional.
- Redesign the hero into a split layout with typography hierarchy, badges, and stat chips that communicate credibility.
- Refresh project, skills, and contact sections with glassmorphic surfaces, neon borders, and motion-friendly spacing while keeping the existing content.

## Impact
- Affected specs: `site-presentation`
- Affected code: `src/App.tsx`, `src/components/*`, `src/index.css`, `tailwind.config.js`, supporting data where necessary.
